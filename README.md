# Proyecto Final: DilemaBot - Fundamentos de IA
## Asistente Inteligente para el Análisis de Dilemas Éticos en Periodismo y Comunicación

Este repositorio contiene la implementación completa del proyecto final **DilemaBot**, alineado al Reto de Innovación Educativa UTPL (Periodo Octubre 2026 – Febrero 2027).

### 🚀 Acceso Rápido
Toda la solución (Portal Web Educativo, Motor RAG y Widget de Chat) se encuentra en la carpeta [`ia-periodismo-rag/`](./ia-periodismo-rag/):

* **[Documentación Completa y Manual de Uso](./ia-periodismo-rag/README.md)**
* **[Backend y Servidor Django](./ia-periodismo-rag/backend/)**
* **[Motor RAG e Indexación](./ia-periodismo-rag/backend/rag_engine/)**
* **[Corpus de PDFs Validados](./ia-periodismo-rag/data/pdfs/)**
* **[Suite de Pruebas Automatizadas](./ia-periodismo-rag/test_system.py)**

Para ejecutar el proyecto:
```bash
cd ia-periodismo-rag
start.bat
```
O visita `ia-periodismo-rag/README.md` para las instrucciones detalladas paso a paso.
